# Установка MatKlass только через браузер (без программ на ПК)

Инструкция рассчитана на GitHub и Supabase в браузере. На iPhone часть операций неудобна из-за больших файлов и редакторов; если интерфейс начинает мешать, можно открыть те же сайты на компьютере в браузере — устанавливать Node.js, Git или другие программы не нужно.

## A. GitHub: файлы сайта

1. Открой репозиторий `matklass`.
2. Добавь в корень репозитория пять файлов: `index.html`, `app.js`, `config.js`, `style.css`, `README.md`.
3. Если в папке распаковки README отображается без расширения, при создании файла в GitHub используй имя `README.md`.
4. Для вложенных файлов используй GitHub → «Добавить файл» → «Создать новый файл» и указывай полный путь в имени файла:
   - `.github/workflows/pages.yml`
   - `supabase/schema.sql`
   - `supabase/config.toml`
   - `supabase/functions/matklass/index.ts`
5. Содержимое каждого файла копируй из соответствующего файла архива. Не складывай `schema.sql` или `index.ts` в корень: путь важен.
6. После загрузки проверь, что в корне видны `index.html`, `app.js`, `config.js`, `style.css`, `README.md`, а также папки `.github` и `supabase`.

## B. Supabase: база данных

1. Создай проект в Supabase Dashboard.
2. Открой SQL Editor → New query.
3. Скопируй весь `supabase/schema.sql` из архива и вставь в редактор.
4. Нажми Run и проверь, что запрос завершился без ошибок.
5. В SQL Editor не нужно создавать таблицы вручную по одной: схема создаёт их сама.

## C. Supabase: серверная функция через браузер

1. В Supabase Dashboard выбери свой проект.
2. Открой Edge Functions.
3. Нажми Deploy a new function → Via Editor.
4. Назови функцию `matklass`.
5. В редакторе замени стартовый код полным содержимым `supabase/functions/matklass/index.ts`.
6. Нажми Deploy function и дождись успешного статуса.
7. В настройках секретов Edge Functions добавь `TEACHER_CODE` со значением `5673`.
8. Убедись, что функция `matklass` настроена с `verify_jwt = false` (для этого проекта проверка доступа выполняется собственными токенами внутри функции). Файл `supabase/config.toml` содержит эту настройку для CLI; при Dashboard-развёртывании проверь параметр в настройках функции, если он доступен.

Supabase автоматически предоставляет функции серверные переменные `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` (или актуальный secret key в среде проекта). Никогда не копируй секретный/service-role ключ в `config.js` или GitHub.

## D. Подключение сайта

1. В Supabase открой Project Settings → API Keys.
2. Скопируй Project URL и Publishable key (или legacy anon public key).
3. В GitHub открой `config.js` → карандаш «Изменить».
4. Замени только `YOUR-PROJECT` и `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY` своими публичными значениями.
5. Сохрани изменения через «Зафиксировать изменения».

`config.js` должен содержать только URL проекта и публичный ключ. PIN `5673`, service-role key, secret key и пароль базы данных там запрещены.

## E. GitHub Pages

1. В репозитории открой Settings → Pages.
2. В разделе Build and deployment выбери Source: GitHub Actions.
3. Открой вкладку Actions и дождись зелёного успешного запуска `Publish MatKlass`.
4. Адрес сайта будет `https://ТВОЙ_ЛОГИН.github.io/matklass/`.

## F. Проверка до использования

Используй только вымышленные имена. Создай одну тестовую работу и проверь:

- вход преподавателя с PIN `5673`;
- вход ученика по имени и фамилии;
- публикацию и отображение работы ученику;
- тестовый ответ, числовой ответ `1/2` при правильном ответе `0.5`, и развёрнутый ответ;
- генерацию 10 уникальных числовых вариантов;
- таймер и запрет изменения после завершения;
- мониторинг, аннулирование после отсутствия активности более 5 секунд;
- ручную проверку, ведомость, шкалу оценок и CSV.

Не используй настоящие ФИ и оценки, пока преподаватель и учебное заведение не разрешили хранение этих данных в выбранном облачном сервисе.
