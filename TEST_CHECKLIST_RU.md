Ставь отметку только после фактической проверки в развёрнутом проекте.

## Подключение
- [ ] `config.js` содержит правильный Project URL и публичный ключ.
- [ ] SQL `schema.sql` выполнен без ошибок.
- [ ] Edge Function `matklass` развёрнута.
- [ ] Серверный секрет `TEACHER_CODE` установлен в `5673`.
- [ ] GitHub Pages опубликован успешно.

## Преподаватель
- [ ] PIN `5673` открывает кабинет.
- [ ] Неверный PIN отклоняется.
- [ ] Можно создать работу по алгебре.
- [ ] Можно создать работу по геометрии.
- [ ] Можно создать тестовые, числовые и развёрнутые задания.
- [ ] Генератор создаёт указанное число уникальных вариантов.
- [ ] Невалидная формула не оставляет частично добавленные задания.
- [ ] Можно сохранить и повторно выбрать шаблон.
- [ ] Можно опубликовать и скрыть работу.
- [ ] Мониторинг показывает статусы учеников.
- [ ] Развёрнутые ответы появляются в ручной проверке.
- [ ] Баллы и комментарий ручной проверки сохраняются.
- [ ] Итоговая ведомость показывает баллы, проценты и оценку.
- [ ] CSV открывается корректно.

## Ученик
- [ ] Вход работает без отдельной регистрации.
- [ ] Ученик видит только опубликованные работы.
- [ ] Ответы сохраняются после изменения поля.
- [ ] `1/2`, `0.5` и `2^3` сравниваются как числовые значения.
- [ ] Таймер отсчитывает время.
- [ ] После завершения нельзя менять ответы.
- [ ] Досрочное завершение работает.
- [ ] При потере активности более 5 секунд сервер аннулирует попытку.

## Ограничение

Этот чек-лист не считается пройденным автоматически после публикации кода. Каждый пункт нужно проверить в реальном развернутом проекте с тестовыми данными и несколькими браузерами/устройствами. Браузерные ограничения и задержки сети не позволяют гарантировать обнаружение каждого закрытия страницы ровно через 5 секунд.
