# МатКласс — исходный проект для развёртывания и проверки

MatKlass — адаптивное веб-приложение для создания, проведения и проверки контрольных и самостоятельных работ. Фронтенд публикуется через GitHub Pages, серверная логика и база данных работают на Supabase. Платные API не используются.

## Функции

- Кабинет ученика без регистрации: вход по имени и фамилии.
- Кабинет преподавателя: постоянный четырёхзначный PIN `5673`, который задаётся серверным секретом `TEACHER_CODE`.
- Создание работ по алгебре и геометрии; название, тема, сложность, длительность и публикация.
- До 80 заданий в одной работе: тестовые варианты, числовые ответы с допуском и развёрнутые ответы для ручной проверки.
- Математическая клавиатура.
- Генератор серии числовых заданий с переменными `{a}`, `{b}`, `{c}` (и совместимой `{n}`), диапазонами значений и безопасным вычислением арифметических формул.
- Сохранение шаблонов на сервере.
- Таймер, сохранение ответов, серверная проверка времени и присутствия.
- Мониторинг активных, завершённых и аннулированных попыток.
- Автоматическая проверка тестов и числовых ответов; числовые ответы могут быть арифметическими выражениями (например, `1/2` и `0.5`); ручная проверка развёрнутых решений.
- Итоговая ведомость по выбранной работе, проценты, оценка по настраиваемой шкале и экспорт CSV.
- RLS включён, прямой доступ `anon`/`authenticated` к таблицам закрыт; доступ к данным идёт через Edge Function с серверным ключом.

## 1. Создать Supabase проект

1. Открой https://supabase.com/dashboard и создай проект.
2. В SQL Editor создай запрос и вставь весь файл `supabase/schema.sql`. Нажми Run. Скрипт создаёт таблицы и включает политики доступа. Его можно запускать повторно для добавления новых колонок.
3. В Project Settings → API скопируй Project URL и публичный Publishable/anon key.
4. Открой `config.js` и вставь значения в `SUPABASE_URL` и `SUPABASE_ANON_KEY`. Публичный ключ предназначен для браузера; секретный ключ сюда вставлять нельзя.

## 2. Установить Node.js и Git на Windows

Установи Node.js LTS с https://nodejs.org/ и Git с https://git-scm.com/download/win. Распакуй проект в папку, например `C:\MatKlass`. Открой PowerShell именно в `matklass_free`.

Проверь: `node -v` и `git --version`.

## 3. Опубликовать Edge Function

В PowerShell выполни по очереди:

```powershell
npx supabase login
npx supabase link --project-ref ТВОЙ_PROJECT_REF
npx supabase secrets set TEACHER_CODE=5673
npx supabase functions deploy matklass
```

`ТВОЙ_PROJECT_REF` — идентификатор проекта из Supabase. При первом запуске CLI может запросить подтверждение установки. PIN преподавателя хранится только в серверном секрете. Чтобы изменить его, повтори команду с новым PIN из четырёх цифр.

## 4. Опубликовать сайт на GitHub Pages

1. На GitHub создай репозиторий `matklass`. Для GitHub Pages репозиторий может быть Public. Не помещай в репозиторий PIN, `service_role`, пароль базы данных или другие секреты.
2. Из папки `matklass_free` выполни, подставив свой логин GitHub:

```powershell
git init -b main
git add .
git commit -m "MatKlass initial release"
git remote add origin https://github.com/ТВОЙ_ЛОГИН/matklass.git
git push -u origin main
```

3. На GitHub открой Settings → Pages → Build and deployment → Source → GitHub Actions.
4. Открой Actions и дождись успешного workflow `Deploy static site to Pages`.
5. Адрес будет `https://ТВОЙ_ЛОГИН.github.io/matklass/`.

## 5. Создать первую работу

1. Открой сайт и войди в кабинет преподавателя с PIN `5673`.
2. Во вкладке «Создать работу» заполни название, раздел, тему, сложность и время.
3. Добавь задания. Для теста введи варианты построчно и правильный вариант. Для числового ответа укажи правильное число и допустимую погрешность. Для развёрнутого решения укажи критерий проверки.
4. Чтобы сгенерировать серию заданий, задай условие с переменными и формулу. Пример: условие `Вычисли 3*{a}+{b}`, формула `3*a+b`, диапазон a 1–10, b 1–10, число заданий 10. Генератор подставит новые числа и рассчитает ответ для каждого задания. Формулы используют `+ - * / ^`, скобки и числа. Это вычислительный шаблонизатор, а не система компьютерной алгебры: произвольные уравнения и символьные преобразования он сам не выводит.
5. При необходимости задай пороги оценок 3, 4 и 5 в процентах. Укажи все три порога; они должны идти по убыванию. Если оставить поля пустыми, система покажет баллы без оценки.
6. Отметь «Сразу сделать работу доступной ученикам» и сохрани.

## 6. Как проходит работа

Ученик вводит имя и фамилию, выбирает опубликованную работу и отвечает. Ответы сохраняются на сервере при изменении поля. По окончании времени работа завершается автоматически. Тестовые и числовые ответы проверяются автоматически; развёрнутые ответы попадают во вкладку ручной проверки. После проверки результаты доступны в итоговой ведомости. CSV можно скачать кнопкой в ведомости.

## Проверки перед реальным использованием

1. Создай тестовую работу с одним тестовым, одним числовым и одним развёрнутым заданием.
2. Проверь числовые ответы `0.5`, `1/2`, `2^3` и ответ с десятичной запятой.
3. Сгенерируй серию из 10 уникальных вариантов; проверь, что формула ответа использует только переменные, показанные в условии.
4. Открой работу в двух отдельных браузерах и проверь сохранение разных ответов.
5. Проверь досрочное завершение, окончание таймера, ручную проверку, ведомость и CSV.
6. Проверь возврат во вкладку до и после 5 секунд отсутствия.

## Важные технические ограничения

- Проверка активности выполняется браузером и сервером: клиент отправляет heartbeat примерно каждые 4 секунды, сервер аннулирует попытку, если маркер активности отсутствует более 5 секунд. Браузер и сеть не дают абсолютной гарантии обнаружить закрытие вкладки ровно через 5 секунд; возможны ложные аннулирования при нестабильной сети или ограничении фоновых вкладок.
- Учительский PIN из четырёх цифр имеет ограниченную стойкость. Сервер применяет ограничение попыток входа, но PIN следует сообщать только преподавателю и менять при подозрении на раскрытие.
- Это не сертифицированная экзаменационная система. Перед реальным использованием проведи полный тест с преподавателем и получи разрешение учебного заведения на хранение ФИ и оценок в стороннем облаке. До этого используй только вымышленные данные.
- Бесплатные тарифы сторонних сервисов могут менять квоты, ограничения и условия. Проверяй их в актуальной панели Supabase/GitHub.
- После изменения кода на GitHub сайт автоматически пересобирается через GitHub Actions. После изменения SQL повторно выполни миграционный SQL в Supabase. После изменения Edge Function повтори `npx supabase functions deploy matklass`.
